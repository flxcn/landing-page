One last check before you continue.

Before we hand you off to the feedback page, please confirm that the Princeton Search Engine Engagement Study extension is set to Always Allow on All Websites in Safari. This is required for the study to work correctly.

  1. Open the Settings app, scroll down, and tap Safari.

  2. Under General, tap Extensions, then tap Princeton Search Engine Engagement Study.

  3. Make sure the extension is toggled on, and that All Websites is set to Allow (not "Ask" or "Deny"). Permissions for google.com and search-engine-engagement.cs.princeton.edu should also be set to Allow.

Once you have verified this, click Continue below to proceed to the feedback page.
